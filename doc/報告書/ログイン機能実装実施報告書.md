## 🎯 実装目的

食品開発ナレッジベースシステムにおける、セキュアなユーザー認証機能を提供するログイン画面を実装する。

## 📝 実装内容

### 1. 型定義の作成

**ファイル**: `types/auth.ts`

- `LoginFormData` - ログインフォームのデータ構造
- `User` - ユーザー情報の構造
- `AuthState` - 認証状態の管理構造

```typescript
export interface LoginFormData {
  email: string;      // ユーザーのメールアドレス
  password: string;   // ユーザーのパスワード
}

export interface User {
  id: string;         // ユーザーの一意な識別子
  email: string;      // メールアドレス
  name: string;       // ユーザー名
  role: 'admin' | 'user';  // 権限（管理者 or 一般ユーザー）
}

export interface AuthState {
  user: User | null;           // ログイン中のユーザー情報
  isAuthenticated: boolean;    // ログイン状態のフラグ
  login: (email: string, password: string) => Promise<void>;
  logout: () => void;
}
```

### 2. 基本UIコンポーネントの作成

#### Input コンポーネント

**ファイル**: `components/ui/Input.tsx`

**主な機能**:
- ラベル表示機能
- エラーメッセージ表示
- 必須項目マーク（アスタリスク）
- `forwardRef`によるref転送対応（react-hook-form連携用）
- カスタムスタイル対応

**特徴**:
- `InputHTMLAttributes`を継承し、標準的なinput属性を全て利用可能
- TailwindCSSによるレスポンシブデザイン
- フォーカス時の視覚的フィードバック

#### Button コンポーネント

**ファイル**: `components/ui/Button.tsx`

**主な機能**:
- 3種類のバリエーション（primary、secondary、outline）
- 全幅表示オプション
- ローディング状態表示
- 無効化状態の制御

**特徴**:
- `ButtonHTMLAttributes`を継承
- ホバーエフェクト
- トランジションアニメーション

### 3. 認証状態管理ストアの作成

**ファイル**: `store/authStore.ts`

**実装機能**:

- 認証状態の永続化準備

**デモ認証情報**:
- メールアドレス: `admin@example.com`
- パスワード: `password`

### 4. ログインページの実装

**ファイル**: `app/login/page.tsx`

**実装機能**:
- メールアドレス・パスワード入力フォーム
- パスワード表示/非表示切替機能

**設定内容**:
- プライマリカラー: `#007A5A`（デザイン要件に準拠）
- セカンダリカラー: `#D1FAE5`
- アクセントカラー: `#3B82F6`
- コンテンツパス: `app/`, `components/`, `pages/`を対象

**重要なポイント**:
- TailwindCSS v4では`@import "tailwindcss"`を使用する際、`@tailwindcss/postcss`パッケージが必須
- 従来の`@tailwind base/components/utilities`ディレクティブから移行

### 1. 開発サーバーの起動

```bash
npm run dev
```

### 2. ログイン画面へアクセス

ブラウザで以下のURLにアクセス:
```
http://localhost:3000/login
```

### 3. ログイン操作

**正常系**:
- メールアドレス: `admin@example.com`
- パスワード: `password`
- 期待動作: `/search` へリダイレクト

**異常系テスト**:
1. 空欄でログイン → バリデーションエラー表示
2. 不正なメール形式 → エラーメッセージ表示
3. パスワード5文字以下 → エラーメッセージ表示
4. 不正な認証情報 → 「ログインに失敗しました」表示

### 4. パスワード表示切替

- 目のアイコンをクリック → パスワードの表示/非表示が切り替わる
