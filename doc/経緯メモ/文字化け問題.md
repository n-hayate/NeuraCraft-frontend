# 文字化け問題の記録

**発生日**: 2025-11-23
**問題**: ファイル名とメタデータの日本語が文字化けする

---

## 症状

### ファイルアップロード時の文字化け

**元のファイル名**:
```
【confidential】カルボナーラソース_凝固防止、分離防止_エマヒートLV、D-34、シミコマーズ_C社_ID3294_221027荒木.xlsx
```

**バックエンドで保存されたファイル名**:
```
?confidential??????????_?????????_?????LV?D-34???????_C?_ID3294_221027??.xlsx
```

**メタデータの文字化け**:
```json
{
  "final_product": "???",
  "issue": "???",
  "ingredient": "???",
  "customer": "???",
  "trial_id": "???",
  "author": "???"
}
```

---

## 原因

### 1. バックエンド側の文字エンコーディング設定不足

**推測される問題箇所**:
- FastAPIのファイルアップロード処理でUTF-8が正しく扱われていない
- FormDataの日本語フィールドが正しくデコードされていない
- データベースの文字セット設定が不適切

### 2. 確認できていること

**✅ フロントエンド側は正常**:
- ブラウザのNetworkタブで確認すると、リクエストは正しくUTF-8で送信されている
- FormDataに日本語が正しく含まれている

**❌ バックエンド側で文字化け**:
- レスポンスで返ってくる `original_filename` が文字化け
- メタデータフィールド（`final_product`、`issue`など）も文字化け

**✅ Azure Blob URLは正常**:
```
https://blobeastasiafor10th.blob.core.windows.net/files/d8f4a600-c739-473e-8adf-a205e360aba7-%E3%82%AB%E3%83%AB%E3%83%9C%E3%83%8A%E3%83%BC%E3%83%A9%E3%82%BD%E3%83%BC%E3%82%B9_...
```
→ URLエンコードされた日本語は正常（`%E3%82%AB` = 「カ」のUTF-8エンコード）

---

## 解決策

### バックエンド側で必要な修正

#### 1. FastAPIのファイルアップロード処理を修正

```python
from fastapi import UploadFile

@app.post("/api/v1/files/")
async def upload_file(
    uploaded_file: UploadFile = File(...),
    final_product: str = Form(...),
    # ... 他のフィールド
):
    # ファイル名を正しくUTF-8としてデコード
    filename = uploaded_file.filename
    if isinstance(filename, bytes):
        filename = filename.decode('utf-8')

    # メタデータも正しくUTF-8として扱う
    # ...
```

#### 2. データベースの文字セット設定

**Azure SQL Database**の場合:
```sql
-- データベースの文字セット確認
SELECT name, collation_name
FROM sys.databases
WHERE name = 'your_database_name';

-- 文字セットをUTF-8に変更（必要に応じて）
ALTER DATABASE your_database_name
COLLATE Japanese_CI_AS;
```

#### 3. FastAPIアプリケーションの設定

```python
from fastapi import FastAPI
from fastapi.responses import JSONResponse

app = FastAPI()

# レスポンスのデフォルトエンコーディングをUTF-8に設定
@app.middleware("http")
async def add_charset_to_content_type(request, call_next):
    response = await call_next(request)
    if "application/json" in response.headers.get("content-type", ""):
        response.headers["content-type"] = "application/json; charset=utf-8"
    return response
```

#### 4. pyodbcの設定（Azure SQL使用時）

```python
# connection stringにエンコーディングを明示
connection_string = (
    "DRIVER={ODBC Driver 17 for SQL Server};"
    "SERVER=your_server.database.windows.net;"
    "DATABASE=your_database;"
    "UID=your_username;"
    "PWD=your_password;"
    "charset=UTF-8"  # ←これを追加
)
```

## 検証方法

### 1. バックエンドのログ確認


### 2. データベースの文字コード確認
```sql
-- テーブルの文字セット確認
SELECT
    TABLE_NAME,
    COLUMN_NAME,
    COLLATION_NAME,
    CHARACTER_SET_NAME
FROM INFORMATION_SCHEMA.COLUMNS
WHERE TABLE_NAME = 'files';
```

### 3. curlコマンドでテスト
